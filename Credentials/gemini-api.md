# 🤖 คู่มือการขอ API Key จาก Google Gemini (AI Studio)

Google Gemini เป็นโมเดล AI ที่เก่งและที่สำคัญคือ **มีโควต้าให้ใช้งานฟรี** (Free Tier) ซึ่งเพียงพอสำหรับการเรียนรู้ในชั้นเรียนแบบสบายๆ

---

## 🎯 ขั้นตอนที่ 1: เข้าสู่ Google AI Studio

1. เปิดเว็บเบราว์เซอร์และไปที่: [Google AI Studio (aistudio.google.com)](https://aistudio.google.com/app/apikey)
2. ล็อกอินด้วยบัญชี Google ของคุณ (Gmail)
3. ยอมรับข้อตกลงการใช้งาน (Terms of Service) หากมีหน้าต่างเด้งขึ้นมา

---

## 🔑 ขั้นตอนที่ 2: สร้าง API Key

1. ที่เมนูด้านซ้ายมือ คลิกที่ **"Get API key"** (หรือไอคอนรูปกุญแจ)
2. คลิกปุ่มสีฟ้าปุ่มใหญ่ **"Create API key"**
3. ระบบจะให้เลือกโปรเจกต์ (Google Cloud Project)
   - หากคุณเคยทำ Google OAuth มาก่อน คุณสามารถเลือกโปรเจกต์นั้นได้เลย
   - หรือคลิก **"Create API key in new project"** เพื่อสร้างโปรเจกต์ใหม่เฉพาะสำหรับ Gemini
4. รอระบบประมวลผลสักครู่
5. เมื่อเสร็จสิ้น จะมีหน้าต่างแสดง **API Key** (เป็นตัวอักษรยาวๆ ที่ขึ้นต้นด้วย `AIza...`)
6. คลิกปุ่ม **Copy** เพื่อคัดลอกคีย์เก็บไว้

> ⚠️ **คำเตือน:** ห้ามส่ง API Key นี้ให้คนอื่น หรือนำไปแปะในโค้ดที่อัปโหลดขึ้น GitHub เด็ดขาด เพราะหากมีคนนำไปใช้จนเกินโควต้า บัญชีของคุณอาจถูกระงับได้

---

## 🔌 ขั้นตอนที่ 3: นำไปใส่ใน n8n

1. กลับมาที่หน้าต่าง n8n ของคุณ
2. เพิ่ม Node ที่ใช้เชื่อมต่อกับ Gemini เช่น:
   - `Google Gemini Chat Model` (อยู่ในหมวด Advanced AI)
3. ดับเบิลคลิกที่ Node เพื่อเปิดหน้าตั้งค่า
4. ที่ช่อง **Credential to connect with**
5. เลือก **Create New Credential**
6. จะมีหน้าต่างให้กรอกข้อมูล:
   - **Credential Name**: ตั้งชื่อให้จำง่าย เช่น `My Gemini Free Key`
   - **API Key**: วางคีย์ (Paste) ที่ก๊อปปี้มาจากขั้นตอนที่ 2 ลงไป
7. กดปุ่ม **Save** ที่มุมขวาบน

🎉 **เสร็จเรียบร้อย! ตอนนี้ n8n ของคุณสามารถคุยกับ Gemini ได้แล้ว**

---

## 📊 ข้อมูลเกี่ยวกับ Free Tier (อัปเดต ปี 2026)

บัญชีฟรีของ Google Gemini (สำหรับรุ่นมาตรฐานเช่น Gemini 1.5 Flash) มักจะมีโควต้าดังนี้:
- **RPM (Requests Per Minute)**: ประมาณ 15 ครั้งต่อนาที
- **RPD (Requests Per Day)**: ประมาณ 1,500 ครั้งต่อวัน
- **ข้อควรระวัง**: ข้อมูลที่ส่งผ่าน Free Tier อาจถูกนำไปใช้ฝึก (Train) โมเดลของ Google ได้ **ห้าม** ส่งข้อมูลส่วนบุคคลที่เป็นความลับ (เช่น รหัสผ่าน, ข้อมูลลูกค้า) เข้าไปเด็ดขาด
