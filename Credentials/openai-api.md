# 🧠 คู่มือการขอ API Key จาก OpenAI (ChatGPT)

OpenAI เป็นผู้ให้บริการโมเดลภาษาขนาดใหญ่ที่ได้รับความนิยมที่สุด (เช่น GPT-4o) เหมาะสำหรับการทำ AI Agent ขั้นสูง แต่มีเงื่อนไขสำคัญคือ **คุณต้องผูกบัตรเครดิต/เดบิตก่อนจึงจะใช้งาน API ได้** แม้จะมี Credit ฟรีแถมมาให้ก็ตาม

---

## 🛑 ข้อควรรู้ก่อนเริ่ม

- **ไม่ได้ใช้ฟรีทั้งหมด**: ไม่เหมือนกับ ChatGPT บนเว็บ การใช้ API ของ OpenAI จะคิดเงินตามปริมาณคำ (Tokens) ที่คุณส่งเข้าไปและที่ AI ตอบกลับมา
- **ต้องเติมเงิน (Prepaid)**: ปัจจุบันระบบส่วนใหญ่บังคับให้เติมเงินขั้นต่ำ $5 ก่อนจึงจะใช้งานได้
- **แยกบัญชีกับ ChatGPT Plus**: แม้คุณจะจ่ายรายเดือน ChatGPT Plus แล้ว แต่ฝั่ง API ก็ต้องจ่ายแยกต่างหาก

---

## 🎯 ขั้นตอนที่ 1: สมัครและล็อกอินเข้า Platform

1. ไปที่เว็บไซต์: [platform.openai.com](https://platform.openai.com/)
2. ล็อกอินด้วยบัญชีที่คุณต้องการใช้งาน
3. (ถ้ายังไม่มีบัญชี) ให้กด Sign up และทำตามขั้นตอนการสมัคร

---

## 💳 ขั้นตอนที่ 2: ตั้งค่าการชำระเงิน (Billing)

คุณจะไม่สามารถใช้ API Key ได้เลยถ้าข้ามขั้นตอนนี้!

1. ที่เมนูด้านซ้ายมือ หรือคลิกที่ไอคอนเฟือง (Settings) มุมขวาบน
2. ไปที่เมนู **"Billing"**
3. คลิก **"Add payment details"**
4. เลือกว่าคุณเป็น Individual (บุคคลธรรมดา) หรือ Company (บริษัท)
5. กรอกข้อมูลบัตรเครดิต/เดบิตของคุณให้ครบถ้วน
6. เลือกระบบเติมเงินอัตโนมัติ (Auto-recharge) **แนะนำให้ตั้งค่าปิด (Off)** เพื่อป้องกันบัตรถูกตัดเงินเกินกว่าที่ตั้งใจไว้
7. เติมเงินเริ่มต้น (มักจะบังคับขั้นต่ำที่ $5 หรือประมาณ 180 บาท)
8. **สิ่งสำคัญ:** ในหน้า **Limits** ให้ตั้งค่า **Usage limit** (ตัวอย่างเช่นตั้งเตือนที่ $10 และตัดการทำงานที่ $15) เพื่อจำกัดงบประมาณ

---

## 🔑 ขั้นตอนที่ 3: สร้าง API Key

1. ที่เมนูด้านซ้าย ไปที่หัวข้อ **"API keys"**
2. คลิกปุ่มสีเขียว **"+ Create new secret key"**
3. ตั้งชื่อคีย์ (Name) เช่น `n8n Class Key`
4. ส่วนของ **Project** และ **Permissions** สามารถปล่อยเป็นค่าเริ่มต้น (Default) ได้
5. กด **"Create secret key"**
6. ⚠️ หน้าต่างป๊อปอัปจะแสดงคีย์ของคุณ (หน้าตาประมาณ `sk-proj-...`)
   - **สำคัญมาก:** คุณจะเห็นคีย์นี้เพียงครั้งเดียวเท่านั้น!
   - กดปุ่ม **Copy** เก็บไว้ในที่ปลอดภัยทันที (เช่น Password Manager)

> 🚨 **ห้ามเด็ดขาด:** ห้ามส่งคีย์นี้ให้เพื่อน ห้ามถ่ายรูปหน้าจอที่มีคีย์ หรือดันโค้ดขึ้น GitHub หากระบบของ OpenAI ตรวจพบว่าคีย์หลุด คีย์นั้นจะถูกยกเลิก (Revoke) ทันทีและบัญชีอาจมีปัญหา

---

## 🔌 ขั้นตอนที่ 4: นำไปใส่ใน n8n

1. กลับมาที่ n8n ของคุณ
2. เพิ่ม Node ที่เกี่ยวข้อง เช่น `OpenAI Chat Model` (อยู่ในหมวด Advanced AI)
3. ดับเบิลคลิกเพื่อเปิดการตั้งค่า Node
4. ที่ช่อง **Credential to connect with**
5. เลือก **Create New Credential** (มองหาตัวเลือก OpenAI API)
6. หน้าต่างตั้งค่าจะให้กรอก:
   - **Credential Name**: เช่น `My OpenAI Key`
   - **API Key**: วางคีย์ที่ก๊อปปี้มาจากขั้นตอนที่ 3 ลงไป
7. กดปุ่ม **Save** เพื่อบันทึก
