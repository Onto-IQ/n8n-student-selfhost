# 🔑 คู่มือการตั้งค่า Credentials สำหรับ n8n

ยินดีต้อนรับสู่คู่มือการตั้งค่า Credentials สำหรับการใช้งาน n8n ในชั้นเรียน! คู่มือนี้จะช่วยให้คุณสามารถเชื่อมต่อ n8n กับบริการภายนอกต่างๆ ได้อย่างปลอดภัยและถูกต้อง

## ⚠️ คำเตือนเรื่องความปลอดภัย (สำคัญมาก!)

1. **ห้าม** ใส่ API Key หรือ Secret ใดๆ ลงไปในไฟล์โค้ด (เช่น `.json`, `.js`) โดยตรง
2. **ห้าม** อัปโหลด (Push) ไฟล์ที่มี API Key ขึ้น GitHub เด็ดขาด
3. **ให้ใช้** ระบบ Credentials ที่มีมาให้ใน n8n เสมอ เพราะระบบจะทำการเข้ารหัส (Encrypt) ข้อมูลเหล่านี้ไว้ในฐานข้อมูลอย่างปลอดภัย

## 💡 คำแนะนำสำหรับการเรียนรู้

1. **สำหรับผู้เริ่มต้น**: แนะนำให้เริ่มจาก [LINE OA](./line-oa.md) และ [Gemini API](./gemini-api.md) ก่อน เพราะสมัครง่ายและใช้งานได้ฟรี
2. **สำหรับงานอัตโนมัติ (Automation)**: ขาดไม่ได้เลยคือ [Google OAuth](./google-oauth.md) เพราะจะช่วยให้เราอ่านอีเมลและบันทึกข้อมูลลง Google Sheets ได้
3. **สำหรับ AI Agent ชั้นสูง**: หากต้องการความฉลาดขั้นสุด แนะนำให้ใช้ [OpenAI](./openai-api.md) หรือ [OpenRouter](./openrouter-api.md) (อาจมีค่าใช้จ่ายเล็กน้อย)

## 🔧 วิธีใช้งาน Credentials ใน n8n ทั่วไป

1. ในหน้า Workflow ของ n8n คลิกที่ Node ที่ต้องการตั้งค่า
2. ในส่วน **Credential to connect with** คลิกปุ่ม `Create New Credential`
3. นำข้อมูล (เช่น API Key, Client ID) ที่ได้จากคู่มือแต่ละตัวมาใส่
4. กด **Save** หรือ **Connect**
5. n8n จะจำ Credential นี้ไว้ คุณสามารถเลือกใช้ซ้ำได้ใน Node อื่นๆ โดยไม่ต้องกรอกใหม่
