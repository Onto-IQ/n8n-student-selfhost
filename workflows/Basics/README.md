# 🎓 n8n Basics: Foundation Workflows

โฟลเดอร์นี้รวบรวม Workflow พื้นฐานที่ออกแบบมาเพื่อการเรียนการสอน (Educational Workflows) สำหรับผู้เริ่มต้นใช้งาน n8n ก่อนที่จะก้าวไปสู่การสร้าง AI Agents

เนื้อหาถูกจัดเรียงลำดับจากง่ายไปยาก พร้อมคำอธิบาย (Sticky Notes) ภาษาไทยในทุกขั้นตอน

## 📂 รายการ Workflows

### 01 - Learn JSON Basics
**เรียนรู้รากฐานของข้อมูลใน n8n**
* **เป้าหมาย:** ทำความเข้าใจประเภทข้อมูล (Data Types) ที่โปรแกรมใช้คุยกัน
* **สิ่งที่ได้เรียนรู้:** String, Number, Boolean, Array, Object, Null
* **หัวใจสำคัญ:** การใช้ Expression `{{ }}` เพื่อดึงข้อมูลข้าม Node

### 02 - Flow Control Demo (IF & Switch)
**การควบคุมทิศทางการทำงาน (ทางเลือก)**
* **เป้าหมาย:** เข้าใจการสร้างเงื่อนไขและแยกสายการทำงาน
* **สิ่งที่ได้เรียนรู้:** 
  * `IF Node` - แยก 2 ทาง (True/False) เช่น เช็คสถานะ VIP
  * `Switch Node` - แยกหลายทาง (3+ ทาง) เช่น ตัดเกรด A, B, F
  * `Merge Node` - การนำเส้นทางที่แยกกันกลับมารวมกัน

### 03 - Flow Control Demo (Loop)
**การควบคุมทิศทางการทำงาน (วนซ้ำ)**
* **เป้าหมาย:** เข้าใจวิธีจัดการข้อมูลที่เป็นชุด (Array) หรือหลายๆ รายการ
* **สิ่งที่ได้เรียนรู้:**
  * `Item Lists (Split Out)` - แตก Array ใหญ่ออกเป็น Item ย่อยๆ
  * `Loop Node (Split in Batches)` - วนลูปทำงานทีละ 1 Item จนครบ
  * การลากเส้นกลับ (Loop Back) เพื่อให้ลูปทำงานต่อเนื่อง

### 04 - Data Transformation
**การเตรียมและแปลงข้อมูล**
* **เป้าหมาย:** การทำความสะอาดข้อมูลดิบให้พร้อมใช้งาน (สำคัญมากเมื่อต้องจัดการผลลัพธ์จาก AI)
* **สิ่งที่ได้เรียนรู้:**
  * `Set Node (Edit Fields)` - เปลี่ยนชื่อฟิลด์, คัดกรองและตัดข้อมูลขยะทิ้ง
  * `Code Node` - เขียน JavaScript พื้นฐานเพื่อจัดการข้อมูลที่ซับซ้อน เช่น การต่อข้อความ หรือคำนวณตัวเลข

### 05 - Working with External APIs
**การเชื่อมต่อกับโลกภายนอก**
* **เป้าหมาย:** เข้าใจการคุยกับระบบอื่นผ่าน API (พื้นฐานสำคัญของการสร้าง AI Tools)
* **สิ่งที่ได้เรียนรู้:**
  * `HTTP Request (GET)` - การเรียกดูข้อมูลจาก Public API
  * `HTTP Request (POST)` - การส่งข้อมูลออกไปยังระบบอื่น
  * เข้าใจแนวคิดเรื่อง Authentication (API Key, Bearer Token)

### 06 - Webhooks and Triggers
**การเปิดประตูรับข้อมูล**
* **เป้าหมาย:** เข้าใจวิธีตั้งรับข้อมูลจากระบบอื่น (เช่น LINE, Slack, Web Forms)
* **สิ่งที่ได้เรียนรู้:**
  * `Webhook Node` - การสร้าง URL สำหรับรับข้อมูลเข้า
  * การประมวลผลข้อมูลจาก Body ของ Webhook
  * `Respond to Webhook` - การส่งคำตอบกลับไปยังระบบที่เรียกมา

## 🚀 วิธีการใช้งาน (How to Use)

1. เปิดหน้า n8n ของคุณ (เช่น `https://n8n.yourdomain.com`)
2. สร้าง Workflow ใหม่ (กดปุ่ม **+ Add Workflow**)
3. เปิดไฟล์ `.json` ในโฟลเดอร์นี้ที่ต้องการเรียน
4. คัดลอกโค้ดทั้งหมด (`Ctrl+A` -> `Ctrl+C`)
5. วางลงในพื้นที่ว่างของหน้า Workflow ใน n8n (`Ctrl+V`)
6. อ่านคำอธิบายจาก Sticky Notes ตามลำดับหมายเลข และลองกด **Test step** ทีละ Node
